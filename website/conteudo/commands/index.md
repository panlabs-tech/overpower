# Commands

This page covers what is true of every overpower invocation before you reach any single command: how the selectors compose, that each one accepts a comma-separated list or repetition or both, and that mixing selectors of different kinds on one line is expected rather than exotic. It also states the order a plan always runs in — framework, bundle, artifact, MCP — and why that order is fixed rather than the order you typed.
