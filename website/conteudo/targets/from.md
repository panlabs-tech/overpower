# --from

This page covers `--from`: pointing overpower at any GitHub repository and using it as the root of the search instead of the embedded catalog. It covers the URL forms accepted, how a tree path pins a branch, a tag, or a commit so a run is reproducible, and what changes about the plan and about provenance when the content comes from somewhere else.
