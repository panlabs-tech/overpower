# list

This page covers `list`: the four blocks it prints, what each block contains, and the line printed under every description — bare, copy-pasteable, and surviving a pipe unchanged. It also covers the selectors that narrow the output to one framework, one bundle, or one artifact, and the separate screen `list --mcp` prints for MCP servers.
