# overpower

This page introduces overpower as a whole: a CLI that installs curated agent equipment into a repository or a machine, and the three questions its three commands answer — `list` says what there is, `install` writes, `doctor` says whether what was written is still what was written. It also covers why the catalog is not fetched at runtime but embedded in the package, which makes the version you pin the catalog you get, and why that turns `@latest` into a correctness requirement rather than a README flourish.
