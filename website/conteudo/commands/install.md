# install

This page covers `install`: the selectors that name what to write, the plan printed before anything touches disk, and the confirmation that gates it. It covers the flags that change that contract — `--dry-run`, `--yes`, `--force`, `--global` — and what each one gives up. It closes with the wizard, which is not a command: it opens when the line you typed does not close a plan and the terminal can hold a conversation.
