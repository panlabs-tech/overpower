# doctor

This page covers `doctor`: what it inspects, how it decides that what was written is still what was written, and what it reports when it is not. It explains why `doctor` answers for the repository and the machine in a single output — and why, because of that, it has no `--global` flag. It closes on exit code 3: the run succeeded, and the answer is no.
