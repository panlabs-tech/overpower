# Exit codes

This page covers the four exit codes and the distinction each one draws: `0` did what was asked, `1` could not run, `2` you invoked me wrong, and `3` ran, and the answer is no. It explains why a refusal is its own code rather than a failure, and what that buys a script that wraps overpower.
