- **A repository equipped with the overpower can be installed from again.** One
  that has run `overpower install` on itself carries its skill twice — at
  `skills/<name>/`, which is what it offers, and at the runtime's own
  destination such as `.claude/skills/<name>/`, which is where the install put
  it. `--from --skill <name>` found both and refused the line as ambiguous, and
  that refusal was **false**: there is one skill there, and the second path is a
  copy of the first.

  Both searches now skip runtime destinations, derived from the runtime table
  itself so a row added there needs no second edit. The deny-list never overrules
  a URL that already narrowed: pointing `--from` inside a runtime's own folder
  still reaches what is in it, which is the very narrowing the ambiguity message
  asks for. Two genuinely different offers under one root are still refused, and
  still name every candidate.
