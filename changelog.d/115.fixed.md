A tela de `list --mcp` para de prometer o que o install recusa. Uma receita que traz codigo-fonte nao e mais oferecida em escopo de projeto — o install ja recusava e o wizard ja obedecia, so a tela nao. E a linha que `list --mcp <slug> --from <url>` manda copiar carrega a origem: sem ela, colada de volta, saia com exit 2 dizendo que nao existe MCP com esse nome.
