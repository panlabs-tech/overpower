# Install

This page covers how to obtain overpower — running it without installing anything, and installing it as a tool when you want it on the path. It explains the `op` shortcut: what it would save you, why overpower does not create it, and how to make one yourself if you want it. It closes with `--version` as the cheapest evidence that the package arrived whole, catalog included.
